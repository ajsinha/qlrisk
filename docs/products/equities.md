# Equity Products v1.1.0

## Overview

Ownership securities and related derivatives.

## Common Stock

| Category | Description | Typical Vol |
|----------|-------------|-------------|
| **Large Cap** | Market cap > $10B | 15-20% |
| **Mid Cap** | $2B - $10B | 20-25% |
| **Small Cap** | $300M - $2B | 25-35% |
| **Micro Cap** | < $300M | 35-50% |

## Depositary Receipts

| Type | Description |
|------|-------------|
| **ADR** | US-traded foreign stock |
| **GDR** | Globally traded receipt |

## Preferred Stock

- Fixed dividend (priority over common)
- May be cumulative, participating, or convertible
- Lower volatility than common stock

## Warrants & Rights

- **Warrant:** Long-term option issued by company
- **Rights Issue:** Short-term right to buy at discount

## ETFs

| Type | Description | Leverage |
|------|-------------|----------|
| **Standard** | Tracks index 1:1 | 1x |
| **Leveraged** | Multiple of index | 2x, 3x |
| **Inverse** | Opposite of index | -1x |
| **Sector** | Industry-specific | 1x |
| **Thematic** | Theme-based (AI, ESG) | 1x |

## SA-CCR Treatment

- Single stock: SF = 32%
- Index: SF = 20%
